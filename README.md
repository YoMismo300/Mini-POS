# Parcial – Desarrollo de Aplicaciones .NET

## Descripción

Este parcial tiene como objetivo evaluar la capacidad para aplicar los conocimientos adquiridos durante la **Clase 05**, mediante el desarrollo de una solución al reto propuesto en la guía de profundización en .NET.

Para la realización de la actividad se debe revisar y seguir cuidadosamente la guía correspondiente a la Clase 05, disponible en el siguiente enlace:

[Guía Clase 05 – Profundización en .NET](https://epimient.github.io/Profundizaci-n_en_NET/#/clase-05/doc)

## Objetivo

Desarrollar una solución funcional utilizando el entorno y las herramientas de **.NET**, aplicando los conceptos y buenas prácticas estudiados durante la clase. El proyecto deberá estar correctamente estructurado y preparado para ser ejecutado por cualquier persona que descargue o clone el repositorio.

## Requisitos de la actividad

La solución debe cumplir con los siguientes requisitos:

* Seguir las indicaciones establecidas en la guía de la Clase 05.
* Desarrollar completamente el reto planteado.
* Utilizar la tecnología y estructura de proyecto correspondientes al ejercicio.
* Incluir todos los archivos necesarios para compilar y ejecutar la aplicación.
* Crear un repositorio **público en GitHub** para almacenar y presentar la solución.
* Incorporar un archivo `README.md` con la información principal del proyecto y las instrucciones para su ejecución.
* Verificar que el proyecto pueda ser clonado, descargado, compilado y ejecutado correctamente desde una ubicación diferente.

## Estructura del repositorio

El repositorio debe contener, como mínimo, los siguientes elementos:

```text
/
├── Código fuente del proyecto
├── Archivos del proyecto .NET
├── README.md
└── Otros archivos necesarios para la ejecución
```

La estructura puede variar dependiendo de las características específicas de la solución desarrollada.

## Ejecución del proyecto

Para ejecutar correctamente el proyecto, se recomienda contar con las herramientas necesarias para el desarrollo de aplicaciones .NET.

Una vez clonado el repositorio, se deben seguir las instrucciones indicadas en este documento para restaurar las dependencias, compilar y ejecutar la aplicación.

Ejemplo:

```bash
git clone (https://github.com/YoMismo300/Mini-POS)
cd Mini-POS
dotnet restore
dotnet build
dotnet run
```

Los comandos anteriores pueden variar dependiendo de la configuración y el tipo de proyecto desarrollado.

## Verificación

Antes de realizar la entrega, se debe comprobar que:

1. El repositorio sea público.
2. Todos los archivos necesarios se encuentren incluidos.
3. El proyecto compile correctamente.
4. La aplicación se ejecute sin errores.
5. Las funcionalidades solicitadas en el reto funcionen de acuerdo con lo establecido en la guía.
6. El proyecto pueda ser descargado o clonado en otra ubicación y ejecutado correctamente.

## Entrega

La entrega del parcial se realizará mediante el **enlace al repositorio público de GitHub** donde se encuentre almacenada la solución completa.

## Conclusión

Este parcial permite demostrar la aplicación práctica de los conocimientos adquiridos en la Clase 05, mediante la construcción de una solución desarrollada en .NET y su correcta organización, documentación y publicación en un repositorio de GitHub.
